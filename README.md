# Overcastly

Archive of Overcastly, a MERN-based social media app focused on weather and storm tracking.

The front-end is mainly written in Typescript and React, while the back-end is written in Node.js/Express.

Part of a project done with Ian Justiz, Bed Pandey, Pablo Pedicino, Max Swietnicki, Vishnu Ganesham, and Josh Miller. 

Original project belonged to a now-deleted GitHub organization (Overcastly). I've tried to keep the original commit history and log available.
